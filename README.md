# Visualization and Educational Tool for Beginners in Cryptography

An interactive desktop application developed as part of my undergraduate thesis at the Department of Computer Science and Telecommunications, University of Thessaly.

This tool is designed to introduce cryptography fundamentals to beginners through intuitive step-by-step visualizations and practical demonstrations of core algorithms.

---

## Features
* **Interactive Visualizations:** Step-by-step breakdown of encryption and decryption processes.
* **Beginner-Friendly Interface:** Clean and accessible Graphical User Interface (GUI) tailored for educational purposes.
* **Core Cryptographic Algorithms:** Implementation of fundamental cryptographic methods to help learners understand underlying concepts.

---

## Tech Stack
* **Language:** Python
* **GUI Framework:** Tkinter / CustomTkinter
* **Libraries:** Standard scientific and visualization libraries (e.g., NumPy, Matplotlib)
